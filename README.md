# 메이플스토리 MVP작 계산기

브라우저에서 캐시 전액/마일리지 병용 구매 조합과 실행 순서를 계산하는 정적 사이트입니다. 서버 API, 데이터베이스, 외부 라이브러리가 필요하지 않습니다.

## 실행과 검증

Node.js에서 `npm test`로 테스트, `npm run build`로 정적 파일 생성, `npm start`로 로컬 실행합니다. 로컬 주소는 http://127.0.0.1:4173 입니다. HTML 파일을 직접 열면 Web Worker 보안 정책 때문에 계산이 동작하지 않을 수 있습니다.

`public/`의 네 파일만 정적 호스팅에 올리면 됩니다. 빌드 명령은 `npm run build`, 배포 디렉터리는 `public`입니다. 비밀키나 환경변수는 없습니다. `.openai/hosting.json`은 연결한 Sites 식별자를 보관합니다.

## 이번 수정

- 구매 전에 캐시와 마일리지가 충분한지 검사합니다. 구매 후 적립분을 이전 결제에 미리 쓰던 고정점 계산을 제거했습니다.
- 보유 마일리지만 사용 / 구매 후 적립분 재사용을 선택할 수 있습니다. 상품별 적립 여부와 남은 적립 한도를 설정할 수 있습니다.
- 정수 수량과 캐시·마일리지 구매가 공유하는 수량 한도를 지킵니다. 빈 한도는 무제한, 0은 구매 금지입니다.
- 작은 입력은 모든 가능한 구매 순서를 탐색합니다. 큰 입력은 복수의 탐욕 초기안과 제한된 폭의 탐색을 사용하며 최적해 미보장을 표시합니다.
- 작업 스레드에서 최대 160,000개 전이를 탐색합니다. UI에서 20초를 초과한 계산은 중단합니다. 입력 변경 시 계산과 기존 결과를 취소합니다.
- 같은 조합의 전액 캐시 구매를 먼저 모아, 실행 가능한 마일리지 구매 순서를 보여줍니다.
- 보유 캐시 원가를 포함해 회수율 과장을 수정했습니다. 전체 사용 캐시 원가와 필요 추가 충전액을 구분합니다.
- 일반 브라우저에서 지원되지 않던 `window.storage` 대신 `localStorage`에 저장합니다. JSON 불러오기는 허용된 필드와 30개 이하의 아이템만 복원합니다.

## 계산 전제와 남은 개선점

1. 목표는 예산 이하에서 **획득 메소 최대화**입니다. 특정 MVP 등급 달성에 필요한 최소 캐시 소비 제약은 아직 없습니다. 목표 금액을 반드시 소비하는 조합은 별도 기능이 필요합니다.
2. 메포는 캐시와 1:1의 실효 구매 비용이라고 가정합니다. 전환 단위, 메포 보유분, MVP 인정 대상 여부는 모델에 별도로 포함하지 않습니다.
3. 상품을 입력 가격에 모두 판매하고, 경매장 수수료는 상품별 동일하며 순수익 메소는 건별 내림합니다. 거래량에 따른 가격 하락은 최대 수량으로 제한하세요.
4. 마일리지 병용액과 적립액은 **구매 1건마다 정수 내림**합니다. 상품별 실제 절사·적립 단위를 확인해야 하며, 묶음 상품은 한 행에 묶음 가격/판매액으로 입력합니다.
5. 재사용 모드는 매 구매 후 적립금을 수령할 수 있을 때만 유효합니다. 청약철회 가능한 상품은 인벤토리 이동 등이 선행될 수 있습니다.
6. 큰 입력은 근사 탐색입니다. 모든 규모에서 최적성을 보장하려면 정확한 정수계획법과 구매 순서 제약을 결합한 엔진이 후속 과제입니다.
7. 보유 마일리지의 취득 원가, 거래 실행, 실시간 시세 조회, 개인 간 데이터 동기화는 포함하지 않습니다.

## 규칙 확인 (2026-09-15)

- [공식 MVP 안내](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/425): 넥슨캐시 사용액 기준이며 일부 상품은 제외되므로 충전액 자체를 MVP 실적으로 볼 수 없습니다.
- [테스트월드 공지](https://maplestory.nexon.com/testworld/news/update/199?page=1): 2026-09-17 구매 적립금의 메이플크레딧 전환 예고. 정식 서버 적용을 확인한 후 마일리지 신규 적립이 중단되면 적립률을 0%로 설정해야 합니다. 메이플크레딧 가치는 계산하지 않습니다.

## 검증 범위

자동 테스트는 자금 선사용 방지, 재사용 모드 차이, 탐욕법 반례, 구매/적립 한도, 입력 검증, 120개 작은 입력의 독립 전수 탐색 대조, 큰 입력의 구매 순서 재생, 탐색 제한 표시를 검사합니다. 시세와 실제 게임 거래 가능성을 보장하는 테스트는 아닙니다.
